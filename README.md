# Mock Alexander Polynomial Computations

This repository contains Python code used to compute the permanents of the
matrices appearing in the examples of the paper:

**Connected Sums of Starred Knotoids in S^2 and the Mock Alexander Polynomial**

The computations verify the mock Alexander polynomial values for the example
knotoids and check the multiplicativity formula under connected sum.

## Requirements

The code requires Python 3 and SymPy.
